# APP Pelaporan MUT

Aplikasi pelaporan MUT (MUT = ? ) yang dirancang untuk membantu proses pelaporan dan pengelolaan data secara lebih terstruktur dan mudah diakses.

## Tentang Proyek

Repository ini berisi aplikasi web sederhana berbasis HTML yang digunakan untuk keperluan pelaporan data MUT. Aplikasi ini dibuat untuk mempermudah pengguna dalam menginput, melihat, dan mengelola laporan secara cepat dan konsisten.

## Fitur Utama

- Form pelaporan yang mudah digunakan
- Tampilan berbasis web yang sederhana dan responsif
- Struktur file yang mudah dipahami dan dikembangkan
- Cocok untuk kebutuhan pelaporan internal atau operasional

## Teknologi

## Cara Menjalankan

1. Clone repository ini:

```bash
git clone https://github.com/trikastain/pi.git
```

2. Masuk ke direktori project:

```bash
cd pi
```

3. Buka file `index.html` di browser Anda.
